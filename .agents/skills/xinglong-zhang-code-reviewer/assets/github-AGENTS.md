## Pull request code reviews

- For CHEMSMART code reviews, read and apply `.agents/skills/xinglong-zhang-code-reviewer/SKILL.md` and its referenced evidence.
- Inspect the requested diff, affected callers, parent classes, tests, and existing review threads before reporting findings.
- Ground each finding in the current code and explain its concrete consequence. Separate correctness defects, OOP/API recommendations, reuse issues, and consistency or documentation concerns.
- Treat review requests as read-only unless the user or configured review integration explicitly authorizes code changes or publication.
- Do not overwrite existing repository instructions when adding this section; merge it with the applicable local guidance.
